02Executive Summary

NMKR Identity is the end-to-end delivery of the F10-funded framework for cryptographically verifying the authenticity of tokenized real-world assets on Cardano. Companies create a self-signed Atala PRISM Decentralized Identifier (DID), pass platform KYC review, receive a signed W3C Verifiable Credential attestation, issue per-project or per-asset credentials under that DID, and export signed CIP-725 metadata that embeds the full proof chain into Cardano token metadata. Over the 28-month project we delivered a production web application, a public verification API, a standalone Python library + CLI, and a bearer-token /api/v1 that lets third-party tools and AI agents mint DIDs and issue credentials programmatically. Live at identity.nmkr.io on Railway, 109 passing tests, full documentation at /docs.

Qualitative impact. Before this project, a Cardano RWA or NFT project could publish a policy ID but had no standardised, verifiable way to prove who was behind it. Buyers had to rely on off-chain trust (Twitter handles, marketplace badges). NMKR Identity gives every issuer on Cardano a cryptographic “who signed this” primitive — portable, non-custodial (projects hold the keys), and readable by any tool that can fetch a URL. The framework was built specifically for RWAs but, as a Catalyst reviewer noted, it “expanded to AI Agents credentials” — the same primitives now support the agent economy emerging on Cardano. As of close-out, 137 DIDs have been created on the platform, each representing a Cardano project with a cryptographically verifiable identity on-chain.

08Why This Project Matters

Identity is the missing layer between a Cardano policy ID and a human-trust decision. Tokenized RWAs, NFTs, stablecoins and agent-issued credentials all live on-chain, but the humans and companies behind them sit in a reputation vacuum: anyone can mint a policy and claim any identity. Every scam, every copycat collection, every impersonation attack starts in that gap. NMKR Identity closes it with three design choices that matter for the ecosystem:

  • Standards-first. W3C DIDs + W3C Verifiable Credentials + CIP-725 — standards the wider web already verifies. Any wallet or marketplace can add a trust indicator by fetching two URLs. Nothing proprietary to learn.
  • Non-custodial. The project holds the signing key; the platform never sees plaintext. The platform attests but never becomes a single point of failure for a project's identity.
  • Agent-ready. The /api/v1 surface lets AI agents and third-party services mint and manage identities on behalf of their users. As Cardano moves toward an agent economy, identity becomes programmable plumbing instead of a manual form — exactly what Milestone 3 reviewers flagged as the standout expansion beyond the original RWA scope.

For the Cardano community this is an infrastructure unlock: every project that follows plugs into the same verification flow, and every wallet/marketplace integration compounds the value for issuers already on the platform. It also hands other Catalyst-funded projects (RWA platforms, stablecoins, DePIN, agent frameworks) an identity layer they no longer have to build themselves.

09What's Next

Immediate (1–3 months): publish the nmkr-identity CLI + Claude-Code skill to PyPI; ship reference wallet/marketplace trust-badge components; track upstream Identus releases to keep the DID schema aligned.

Mid-term (6–12 months): multi-party attestations (regulators, legal registrars, chambers of commerce co-signing the same DID — unlocking regulated RWA issuance); an identity-addendum CIP standardising the DID-linked CIP-725 pattern; programmatic KYC for partner platforms.

Commercialisation & further funding: NMKR Identity will continue as a free-to-use trust primitive within the NMKR product suite, funded by NMKR's existing subscription revenue. Paid tiers are planned for regulated issuers (stablecoins, tokenized securities) requiring multi-party attestations, and for agent platforms requiring higher /api/v1 rate limits. No follow-on Catalyst proposal is planned — the framework is considered feature-complete for its funded scope and further development will be driven by NMKR's commercial roadmap.
